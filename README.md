# MHTri-weakness

Hitzones, elemental weaknesses, status ailments and trap durations for the 18 large monsters of **Monster Hunter Tri** (Wii, European release RMHP08).

**Site:** https://sshikari-hue.github.io/MHTri-weakness/

## What's on the page

- **Hitzones** for every zone: cut, impact, shot, the five elements and KO, with alternate tables (Deviljho enraged, mud-covered Barroth, Agnaktor broken armor, Alatreon state 2).
- **Monster drawings** rebuilt from the in-game 3D models and textures, with each zone colored by how much damage it takes. Hover a zone to highlight it on the drawing and in the table.
- **Elemental weaknesses** ranked by the best zone for each element.
- **Status ailments** (poison, sleep, paralysis, stun, exhaust): threshold, increase after each time, maximum, decay and duration.
- **Trap durations** (pitfall and shock) for every capture attempt, normal / enraged / exhausted.
- **Damage calculator** next to every monster. Switch between Blademaster and Gunner, set weapon, move or ammo and skills, and the zone table shows the damage each part takes instead of the hitzones. One tick applies the same settings to every monster.
  - *Blademaster*: the six melee weapons, each move listed with its Classic Controller input (e.g. `X (hold) → release` for a Great Sword charge, `R → R → R → R` for the Long Sword spirit combo), land and underwater movesets, attack as shown in the menu, sharpness, affinity, element, attack/critical/element skills, Powercharm/Powertalon, spirit gauge and phials.
  - *Gunner*: bowgun ammo with official names, rapid fire, pellet bands, ammo boost skills, Bombardier and element skills, using the Shot hitzone.
  - Monster side: quest multiplier, asleep (×3) and trapped (×1.1).
- Available in the five languages of the European release: Italian, English, French, Spanish and German. Monster, element and ailment names use the official in-game terms; zone names are unofficial.

All values come straight from the game data on the European disc. The damage formula, multipliers, motion values and combo inputs were read from the game code (with help from the community decompilation of the US release); move names are descriptive, not official. The page is a single static HTML file with no dependencies besides web fonts.
